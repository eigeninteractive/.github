# EigenInteractive

**Making it easy for everyone to build abstract strategy games.**

EigenInteractive is an open-source organization focused on creating reusable tools, libraries, and infrastructure for implementing abstract strategy games. Our goal is to let developers focus on designing great games - not rebuilding the same engine, authentication, socials, and networking from scratch.

## What we build

- ♟️ Game engines and rules frameworks
- 🌐 Multiplayer and networking infrastructure
- 🎨 UI components and tooling
- 🧩 Utilities for creating and testing games

## Philosophy

- **Composable** — Small, focused libraries that work well together.
- **Modern** — Type-safe, well-tested, and developer-friendly.
- **Open** — Community-driven and permissively licensed where possible.

Whether you're building a classic board game, inventing a new abstract strategy game, or experimenting with game AI, EigenInteractive aims to provide the foundations you need.
